# RideRadar 

A real-time, interactive **Map-Based Pickup & Ride Confirmation Platform** featuring dynamic route calculation, automated driver assignment, live map telemetry, and multi-tier fare estimation.

---
![Uploading Screenshot.jpg…]()

##  Key Features

* Interactive Map Integration:** Pick exact pickup and destination coordinates directly using interactive map markers or automatic GPS detection.
* Real-Time Route Telemetry:** Displays calculated road distance and travel time estimates using integrated mapping APIs.
* Multi-Tier Vehicle Selection:** Dynamic pricing calculations across multiple ride categories (General, AC, and Royal tiers).
* Automated Driver Matching:** Real-time driver simulation and automated dispatch system with interactive response tracking.
* Analytics & Demo Controls:** Built-in Automated Demo mode and Analytics Studio integration for system testing.

---

##  Tech Stack

* Frontend:** Python, JavaScript, HTML5, CSS3
* Mapping & Location Services:** Google Maps JavaScript API / Leaflet
* State & Real-Time Sync:** WebSockets / Flask / Python backend orchestration
